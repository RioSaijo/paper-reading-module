\subsection{P011 --- Integrating the Brick Schema and Control Description Language for automation and controls in BIM}
\label{paper:P011}
\textbf{Authors:} Esben Visby Fjerbæk, Kevin Michael Smith, Christian Anker Hviid\par
\textbf{Major Category:} BMS, BAS, BACS and Building Automation\par
\textbf{Secondary Category:} BIM and Semantic Information, HVAC and Building Services\par
\textbf{Keywords:} BACS, Brick Schema, Control Description Language, BIM, HVAC controls, Interoperability\par
\paragraph{主な主張}
Brick SchemaでHVAC assets, topology, pointsを表現し, CDLでcontrol logicを表現してBIM由来equipmentへ接続するinformation modelとworkflowを提示した. real ventilation systemで, control sequencesを含むmachine-readable, queryable knowledge graphを構築した. \cite{Fjerbaek:2026BrickCDL}
\paragraph{新規性}
BrickとCDLを単一knowledge graphで接続し, BACSのcontext, sensor-process-actuate, logicをdesignからoperationまでmachine-readableに扱う構成を示した点に特徴がある.
\paragraph{位置付け}
主対象がHVAC controlsとBACS information modelであるためBMS, BAS, BACS and Building Automationを主分類とし, BIM semanticsとHVACを副分類とする.
