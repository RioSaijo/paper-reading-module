\subsection{P012 --- An ontology-aided, natural language-based approach for multi-constraint BIM model querying}
\label{paper:P012}
\textbf{Authors:} Mengtian Yin, Llewellyn Tang, Chris Webster, Shen Xu, Xiongyi Li, Huaquan Ying\par
\textbf{Major Category:} Retrieval, Query, LLM and Agent\par
\textbf{Secondary Category:} BIM and Semantic Information\par
\textbf{Keywords:} Natural language query, BIM retrieval, Ontology, Semantic parser, SPARQL, IFC, Multi-constraint query\par
\paragraph{主な主張}
ontology-aided semantic parserによりmulti-constraint natural language queryをIFC-compliant SPARQLへ変換した. 225 NLQsでoverall query accuracy 91.11\%, attribute constraint extraction 94.3\%, relational constraint extraction 97.77\%を報告した. \cite{Yin:2023OntologyBIMQuery}
\paragraph{新規性}
attribute, relation, value restrictionを論理的に組み合わせるNL queryをmodular ontologyとmodel-specific ontology populationを介してstructured BIM queryへ変換する点に特徴がある.
\paragraph{位置付け}
自然言語からBIM情報をretrieval/queryするinterfaceが研究の中心であるためRetrieval, Query, LLM and Agentを主分類とし, ontology/BIM semanticsを副分類とする.
